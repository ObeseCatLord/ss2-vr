# Event-time ID1 collection — source implemented

This is a connected, default-off diagnostic collector, not accepted grasp
alignment or a request for user testing. No game, debugger, host, headset, firing
or vehicle run occurred. The user remains the primary gameplay tester.

`SS2VR_LAB_IDLE_WEAPON=1` enables the bounded original-animation-End observer and
up to 32 ordinary selected-ID1 idle draw traces. Originals execute once. Scope13
selection retains its existing behavior; no renderer, transport or native
animation/gameplay state machine is replaced.

Inside the original gun invocation, it fixes the admitted owner/weapon/model/eye
identity and copies original placement, tracked placement and calibrated controller
frame. Before original animation End releases query storage, it checks the exact
caller return and active queue, then copies bounded contributing animation value
headers. After native palette production it selects a unique admitted model record,
validates instance/evaluation backlinks and the entire canonical matrix span, and
copies current typed CFG resource-header identity, reflected stretch and pose.
The placement/event/palette identity must agree. Missing, duplicate, nested,
replaced, unbounded or partially copied observations reject; no cached animation
is inferred. Normal completed gun return emits copied values only. Abnormal
retirement remains scalar, with no logging, allocation or native callback.

Native animation End's call site is `DDDE8`; its **return** is `DDDED`.
`CAnimation` is a value object, not a resource. Its copied IDENT/frame-bound/speed
words must not be passed to resource getters. Current CFG header identity does
not establish historical file-byte provenance or anatomy.

The offline reader is `tools/assess_idle_weapon.py`. It binds every record to the
actual compiled source fingerprint/IPC10/wire7, rejects native integer/float range
violations, malformed prefixes, mixed/duplicate/truncated records and unsupported
provenance claims. Its output always leaves historical bytes, positive grasp and
alignment acceptance false. It does not launch a process.

## Consumed ID1 draw stage — source implemented

The existing D3D9 DIP owner now captures up to eight draws from the exact selected
ID1 root or its validated descendants. It validates current model/draw pointers as
exact renderer-array members before dereference, then reuses complete native
model/mesh/draw/palette ownership and actual single-bone mapping. It copies current
child CFG identity, surface/bone names, mapped affine and the existing native clip
reference. No historical pointer registry, geometry replacement or guessed grip.

A separate ID1 layout admission uses declared FLOAT3 positions, u16 indices and
byte weights/local indices, matching stream offsets/strides/identities, and bounded
UV ranges. Managed, usage-zero buffers only; WRITEONLY/dynamic/unknown layouts
are declined. The native buffer admission is narrowly 0..254; absent sentinel255
is rejected. Maximum1490 vertices/1332 triangles is a diagnostic budget, not native
coverage. One privately inspected gun LOD lacks weights/local indices and is
explicitly unsupported; it is not evidence that the runtime selects that LOD.

The same COM owner and lock ledger copy five channels, unlock, hash owned bytes,
then take the second binding/constants/declaration snapshot. Actual shader words
(max512), finite constants(max256) and declaration(max65) are retained for private
interpretation. Shader bytes alone do not establish position equivalence. Existing
output-transaction interference checks extend through original draw and resource
release; any loss rejects the trace. Ordinary allocation failure is locally
contained before exactly-once native forwarding. All eight ownership-helper
scratch vectors live above the explicit native-finally frame. Scope13 retains its
original range/content/geometry admission and exact spans despite larger scratch.

The reader requires schema3 and every declared chunk. Zero draw traces are
explicitly event/pose-only, not geometry completion. `tools/match_idle_geometry.py`
compares every channel hash, format, offset, count and buffer size to a private
candidate index, rejecting absence/ambiguity. It reports consumed input equivalence
only; historical loaded bytes, shader replay, grasp and alignment remain false.

## Offline replay and indexed reference — source implemented

`tools/replay_idle_geometry.py` re-assesses the original log against the compiled
fingerprint, matches all five consumed channels, then verifies original private
asset and exported channel hashes. The portable `idle_position_replay` target
validates bounded VS1.1 framing before reusing the existing position evaluator on
every matched vertex. It compares actual copied program/constants against the
captured native clip reference using the existing tolerance. Unsupported program,
unknown position dependency, unavailable constants or changed projection decline.
Scope13 keeps its exact UV policy; the offline mode does not add native shader
admission. CPU agreement does not prove GPU precision, rasterization or headset VR.

The input conversions follow [Microsoft's vertex type definitions](https://learn.microsoft.com/en-us/windows/win32/direct3d9/d3ddecltype),
and matrix replay follows its [consecutive-row matrix operation](https://learn.microsoft.com/en-us/windows/win32/direct3dhlsl/m4x4---vs).
Successful private replay includes transformed geometry and exact binding identity.
Rejected and event-only observations remain visible; log-wide agreement requires
complete copied coverage instead of silently dropping them.

The older `controller` sample is calibrated grip-position/aim-orientation tracking,
not raw OpenXR grip orientation. Schema3 separately captures uncalibrated grip and
aim **game-world** matrices from the same frozen input, under the existing tracking
bounds. Missing grip is explicit. These are not unbounded OpenXR local-space poses.

`tools/measure_idle_reference.py` reconstructs explicitly annotated triangle points,
requiring exact asset/channel identity, original ordered vertex indices and valid
barycentric weights. It transforms the landmarks through the complete captured
affine before constructing a nondegenerate reference frame, reports reflection and
compares its origin with the uncalibrated grip when available. It rejects malformed
or nonfinite matrices/comparisons. The private hand annotation is a reviewed
geometric convention on a palmar-side, index-side and thumb-side patch. It does
not establish pressure/contact, an OpenXR controller origin, left-hand equivalence
or a justified correction. All positive-grasp/alignment/mutation flags remain false.
OpenXR grip semantics remain a separate reference: [Khronos grip pose](https://registry.khronos.org/OpenXR/specs/1.0-khr/html/xrspec.html#semantic-path-grip-pose).

## User-operated collection preparation

`tools/runtime_lab.py` now has an explicit `idle_weapon_probe` configuration mode.
It requires pinned VR products and one stationary baseline pose, rejects mixed
movement/firing/other diagnostic modes, clears inherited collector selection and
sets the observer only for this run. After the existing scene/isolation/readiness
and neutral projection/eye-image checks, it writes schema3 evidence and returns
before control probes. Existing exact-owned-process cleanup remains in place.
This is a lab-only single-player data collector, not a production multiplayer rule.

No game, debugger, headset, firing or vehicle observation was launched or deployed
for this increment. A fresh private exact-build lab/configuration and final bounded
handoff review are still required before requesting the user observation. Do not
send the user to an older package. The remaining source/runtime questions are actual
copied-program agreement, winning Idle/cache interpretation and physical grip
correspondence. Surface reference measurement alone does not close them. Idle
collection also cannot certify first-use/copy melee release; preserve that separate
native behavior and user acceptance. Assets, indexes, poses and captures stay private.
