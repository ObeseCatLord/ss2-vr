# Scope loaded-buffer / draw boundary audit

Owned fingerprinted Engine.dll/GfxD3D.dll, static instruction evidence only. No runtime, proprietary asset/disassembly redistribution or production hook is part of this audit. This narrows later scope content/cap admission; no implemented optic is claimed.

## Loaded slices

Native public mdlGetVertexPositionD9160..D91F4 proves positions path at surface+20 (format byte, buffer byte+21, offset+24). It resolves the chosen CVertexBuffer from renderMesh+24, reads its native handle+3C and calls gfxLockVertexBuffer8F8E0 with access93, length12 and pathOffset+vertexIndex*formatStride; unlock8FA20 follows. mdlGetTriangleIndicesD9090..D9158 similarly uses renderMesh index array+1C and surface path+18/+19/+1C, with32-bit format8 or16-bit format7. Each public query can resolve native resource proxies; hundreds of individual calls per frame are unsuitable.

mdlGetVertexBufferE67C0..E680B bounds the ordinal against renderMesh+20 then resolves the proxy in renderMesh+24. mdlGetIndexBufferE6810 follows the corresponding+18/+1C count/base. CVertexBuffer::GetHandle7C260..7C263 returns+3C. gfxGetVertexBufferSize8F860..8F890 validates handle1..nativeCount and returns the live renderer handle record's size. Surface triangle/vertex counts come from+8/+C (E6240/E6270); skin count E62D0 additionally requires a valid weights buffer ordinal at+39.

gfxLockIndexBuffer8FA10 is a tail jump to gfxLockVertexBuffer8F8E0; gfxUnlockIndexBuffer8FA90 likewise tail-jumps unlock8FA20. The lock ABI is cdecl(handle,accessType,lengthBytes,offsetBytes). It validates handle and backing storage, bounds the requested range, manages nested-lock/access flags, and either calls the backend static lock or returns CPU storage+offset. Access93 is demonstrated by the original read queries. A successful bounded lock must be matched with exactly one native unlock; never retain the returned pointer. Native validation is not a substitute for caller-side nonnegative/overflow-safe range checks and live resource ownership. The full lock body ends8FA0D; the ordinary CPU-pointer return is8FA02 and invalid-handle return8FA0D.

Thus an admitted actual surface can be checked with bounded whole-slice reads of position/index/weights/local bone indices, using native handles/ranges and hashes of the owned pinned slices, without an alternate mesh importer or per-vertex locks. Loaded weightmap runtime names and actual skeleton/inverse bind still need validation. Filename equality and an offline archive SHA do not establish loaded content identity. No cache keyed only by a recycled resource pointer is justified.

## Current native draw identity

E12B0..E156A walks actual modelRecord, meshRecord and drawRecord arrays. It installs current model at Engine2EAB50 and model matrix from modelRecord+24; for each selected draw it calls DC510 at E14C0 with(drawIndex,flags), prepares software-skinned channels through E1200, unlocks borrowed channels through DC6D0, then invokes DCD10 at E14D3 (returnE14D8). DC510 installs current draw pointer2EAB48, surface2EAB44, vertex count2EAB54 and triangle count2EAB58. These values are transient, tied to the exact native model invocation; a global surface name is insufficient.

DCD10..DD114 is cdecl void(), resets shader channels and sets primitive99 with the native triangle count at DCD29. It builds the actual index/position channels and, when eligible, supplies the palette at2EAC94+draw.paletteStart*48 via shaBoneMatrices77590 at DD0D2. It executes actual shader presets through DADF0, then clears the borrowed palette with shaBoneMatrices at DD106. This is a possible invocation-scoped cap adapter boundary, with exact model/mesh/surface/draw provenance; it also includes shader multipasses, CPU/GPU skinning and native channel lifetimes.

shaRender77300 binds the selected native index channel through _gfxIndexBuffer at7736E and calls _gfxDrawIndices at77388. **Its four arguments are not an arbitrary index subrange.** GfxD3D startup4960 writes backend9C20 into the imported Engine _gfxDrawIndices pointer at4CCB..4CD0. Backend9C20..A057 calls IDirect3DDevice9::DrawIndexedPrimitive atA00B: baseVertexIndex0, minVertexIndex=arg4, numVertices=arg3, startIndex=backend's current index binding offset, primitiveCount=arg2. Treating arg4 as startIndex would corrupt rendering.

A later exact-instance cap exclusion should therefore compare a narrow DrawIndexedPrimitive split (preserving type/base/min/vertex range and modifying only StartIndex/PrimitiveCount) with native index-channel rebind/restore. For the pinned surface only, triangles901..922 can be omitted by drawing901 triangles before them and5 after them; the second start is originalStartIndex+923*3. Every native shader pass must retain the same admission and all unrelated draws must remain unchanged. No such hook is installed; actual index binding/format/range, content identity, reentrancy, failure handling and admitted optic texture ownership remain gates. A guessed minVertexIndex or shared index-buffer/material mutation is rejected.
