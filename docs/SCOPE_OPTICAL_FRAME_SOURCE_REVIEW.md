## Rebuilding the experimental shader tool

Linux build dependencies include a native C compiler, GNU Make, libtool, flex,
bison and the vkd3d1.17 release source. The existing ignored vendor checkout
is `deps/vendor/vkd3d-1.17`; its configure SHA256 is
f5b70b3f0e5c8af8f6d1a001f74eadac6681f4c10a3fe7fdf53fcf9244587c86.
The generated version header target is `include/private/vkd3d_version.h`;
the earlier `include/vkd3d_version.h` target was incorrect.

```bash
mkdir -p build-ui-shader-tools
cd build-ui-shader-tools
../deps/vendor/vkd3d-1.17/configure --disable-tests --disable-demos --disable-doxygen-doc --without-spirv-tools
make include/private/vkd3d_version.h
make -j4 vkd3d-compiler
cd ..
python3 tools/compile_scope_shader.py --compiler build-ui-shader-tools/.libs/vkd3d-compiler
```

The compiler script requires a native ELF executable and writes only ignored
build-scope-shader artifacts. No generated shader binary is packaged, linked,
installed or enabled by these commands. vkd3d is a build-only LGPL2.1-or-later
tool; no compiler/library is distributed in the mod.
