# Sniper draw association and native projection diagnostics

The first private ID13 run reached the exact Jungle scene and native idle sniper
after stock grant and selection. Two completed first-eye/right-hand Black copies
uniquely match the patch mesh's complete buffers and five consumed-channel ranges
and hashes. Alignment remains disabled.

There are two native API submissions but one copied geometry: the Scope surface
contributes API row0; copied Black index0 belongs to API row1/ordinal2. The existing
producer excludes recognized Scope from idle geometry copies. Geometry index and
API ordinal therefore differ in this actual case.

The offline adapter preserves the historical equal-count ordinal route, including
valid ID1 repeated identities. For surplus API rows in schema4/copyLayout1 only,
it requires complete returned, nonoverflowed tables; qualified same-root rows;
unique matches by all seven shared native identity fields, root/render resources,
layout and DrawInput; and an injective, order-preserving map across every copy.
Missing, duplicate, foreign, unqualified or reordered associations reject. It
never chooses a row by whether the arithmetic passes.

Reports expose selected API index/ordinal and incomplete API geometry coverage.
Surplus coverage is determined from observations even when a program falls back
to the legacy calculation. An unsupported arithmetic result retains established
association provenance. Copied-position agreement does not promote whole API,
world/GPU, grasp or alignment acceptance.

After the association repair, both actual copies still reject exact MVP-word
corroboration. The inspected native Poly Bump routine has a different addition
tree at c2.z: the current first-material calculation yields `bcb9aff2`, while
the Poly Bump tree yields uploaded `bcb9aff1`. Its full construction reproduces
all16uploaded words conditionally from copied M/V/P at PC24/nearest. That alone
does not prove which producer executed, its floating-point mode, or cache reuse.
No tolerance was widened and no alternate arithmetic was enabled.

The existing passive paired observer now labels source1 (first material) and
source2 (Poly Bump). Source2 collection is restricted to selected ID13 to preserve
the existing ID1 diagnostic budget. It pins Shaders/Engine fingerprints, exact
slots caller/table and fog caller. Both native intervals are call-free with
contained branches and no floating-point control writes. The same integer-only
sampler copies raw FNSTCW, cache flags, native model/draw keys, M/V/P and cached
Q/R. Original forwarding, pointer return and unwind cleanup are preserved.

Pairs store source before sampling and reject unknown or crossed sources. The
parser accepts source2 as diagnostic data. `native_reference` remains source1-only.
Actual source2 cold/reuse, PC/RC and own-draw factor/constant evidence are required
before a deterministic arithmetic adapter. A Black reuse snapshot cannot borrow
Scope's producer merely because words match.
