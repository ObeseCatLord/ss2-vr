# Serious Sam 2 OpenXR modding field note

Local session note; not published to the shared knowledge base. Search initially found no SS2 entry. Target hashes are in installed-build.json.

Serious Engine 2 is native x86 with many decorated exports. pefile's normal export cap truncates Sam2Game.dll; use max_symbol_exports=65536. Camera/shooting/projection aggregate returns use explicit hidden pointers; weapon Render takes Matrix34f by value (48 bytes). Stock classes use the base shooting-placement virtual slot except sniper. Native player weapon handles are right +0x800 / left +0x804; hand enums are left 0/right 1. Native identical-weapon input routing can couple both guns: override the query by distinct current native entity handles rather than only mapping two controller buttons.

CViewRenCmd Execute mutates shared child pointers and consumes collection-time visibility data. Do not copy/replay that graph. CPuppetEntity Render3D performs native preparation, injection, execution and cleanup; its CPlayer injection includes both weapons. CCanvas CurrentRenderTarget binds through GfxD3D's API pointer implementation, which calls D3D9 RT0/depth setters. Final surface identity/MRT/format gates are required; complete postprocess coverage remains unverified.

One x64 OpenXR host avoids competing runtime paths. Classic D3D9 CPU readback requires non-MSAA and identical source/destination formats/sizes; honor row pitch and owned slot cancellation. Do not apply an old D3D state block while leaving native shader caches at a newer state. CPlayer first-person view delegates through vtable +0xac GetViewOrigin. Base CPuppet purpose 0 gives the pre-animation pose; retain player +0x8c0 stance-height interpolation but reject its 0x7f61b1e6 sentinel. Use the original animated camera only for camera-relative authored weapon offsets. Absolute model calibration contaminates muzzle placement after body movement. Bound head center once and share its correction with both eyes to preserve IPD. Root CViewRenCmd Prepare at Engine return RVA0x14c517 seeds native query CRC from avatar ID; per-eye root identifiers separate occlusion history without replacing the query manager.

ABI3 uses an early atomically published native epoch and snapshot-serialized completion; stale copied snapshots must not republish. Poll existing slots asynchronously, keep cancelled Rendering owned, retain Ready across XR wait retries, and preserve a real complete pair only while its original metadata remains eligible. Both image waits must finish before either upload/release; reacquisition of a cached index suppresses reuse. No-write release changes latest runtime image and invalidates cache. Use real frame-specific eye poses/FOV; never stereo-expand a mono menu screen.

Native command definitions, not spelling, establish movement semantics: X+ right, X- left, Z- forward, Z+ backward. Trigger/wheel interruption needs release gating. Resolve entity handles on the native callback thread and invalidate on deletion; SRW locks alone do not establish native object lifetime.

Verification was compile/static/offline only. No game, headset or runtime execution and no claim of playability. Linux/Proton runtime integration, complex renderer passes and physical muzzle alignment remain open. No game assets, proprietary code or raw operational telemetry are included.
