# Astra borrowed native zoom design disposition

Effective gpt-6-astra/xhigh verified. Architecture GO for the minimal callback
adapter, not source/runtime approval. The review verified pinned owned native
bodies. No native runtime executed. This supersedes the older before-toggle
requirement; the native zoom implementation remains the behavioral reference.

| Recommendation | Disposition |
|---|---|
| BaseStep+1AC is FetchOwner, not OnDelete | Corrected. FetchOwner may reassign owner and BringUp. Revalidate live owner/hand/state after base; no allocation-pin claim. |
| Entity Delete invokes destructor/free after OnDelete | Adopted. Deletion revokes outer contexts before any added dereference; metadata inspected first after native calls. |
| Preserve effect/audio provenance during original deletion | Adopted. Activation revocation differs from cleanup; original self-Deactivate and source destruction retain cleanup context. Abort never marks cleanup complete. |
| Remove before-toggle and post-base inline hooks | Adopted. Initially actual owner558==0; adapter effects suppress native stale owner restoration on both hands. Exported BaseStep wrapper reasserts held, without new activation. |
| External activation must use native BC/D8 | Adopted. It revokes effect ownership independently of left audio provenance; subsequent native restoration remains original. |
| Use current native entity-manager execution context | Adopted. Preparation alone grants no activation; unrelated/nested managers cannot inherit permission. |
| Preserve frozen historical ON and OFF | Adopted. Existing intervalZoomMask supplies server desired at Step, Fire and post-base; original damage executes. |
| Retain bounded per-source cleanup through source deletion | Adopted. 128 records; no timers, live eviction, deferred pointers or native state machine. Capacity sufficiency unverified; exhaustion declines new activation. |

Native nativeFOV is shared owner+858. Independent weapon flags/time/damage do
not make it an independent optic projection. Actual optics remain separate
required work. User forbids game/headset/network execution; offline checks
must not be characterized as runtime proof.
