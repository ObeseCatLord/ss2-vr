# Primary join — reference equivalence before expanding native action calls

Main architecture comparison after immutable-adapter review. This does not
approve production. The completed Astra/xhigh decision below authorizes a bounded
source vertical. Native history, mapping/blocking, callback
order, weapon FSM and RPC remain the behavioral reference. No native execution.

## Demonstrated defects versus unproved assumptions

The initial adapter's midoperator revocation and nested synthetic-neutral policy
were demonstrated defects: they could erase history after a delivered high or
dispatch nested releases. Withdraw both. An immutable invocation projection fixes
that specific temporal inconsistency but is not itself complete approval.

Native stock callbacks are not all no-ops. Charged Cannon release can fire,
fallback/equip/RPC and owner callbacks are reachable. No complete immediate swap,
same-pawn reentry or deletion witness was established in the bounded audit.
Missing closure is not evidence that replacing adjacent command/correction
systems is required. A review must identify what additional risk this narrow
read substitution introduces versus the same virtual primary accepted as native
brain input, rather than demand arbitrary backend purity from native code retained
unchanged in both designs.

## Candidate A — immutable virtual current bits

Five scalar sites replace selected current-primary reads; native history store
and all callbacks remain original. For an admitted invocation, managed mask03
and projected valueV remain fixed until native history commit. Original unmanaged
bits, blocking and flip calculation remain native. Same-pawn nested consumer policy
must be explicitly reviewed: synthetic neutral is rejected; preserving the same
captured virtual sample is a possible reference-equivalent hypothesis, not GO.
Later independent held invocations may validate/revoke without rewriting committed
history. Lifecycle invalidation never repairs native memory or introduces new high.

Under constant virtual-current V, the original operator sees the same primary
values as an ordinary stable accepted input. The helper adds no native call,
subject dereference, allocation, brain store, callback or history state machine.
This equivalence needs actual consumer coverage and invalidation semantics: a
native callback that observes/mutates primary through an unadapted path, or a
demonstrated binding/topology change that alters consumption, can distinguish it.
Preserve recognition separately from valid high and reserve neutral before
reentrant preparation. Wrapper validation must not become another input sampler.

Relevant open evidence is therefore exact current-bit consumer coverage, callback
input invalidation and same-pawn nested consumption, with native identity checks.
Full purity of unrelated sound/resource routines alone is not a design objective.
If the narrow native call/data flow cannot establish those contracts, decline
production A and record the concrete gap.

## Candidate B — original accepted-action entry

Original ProcessPlayerControls(byte,Vec3,Vec3) forwards a56-byte ClientAction,
including native body/support/group/sequence/correction information. Accepting
frozen high and subsequent low immediately before the ordinary operator could
reuse native storage and history rather than the five sites. Determine an actual
supported partial-primary setter first. Do not duplicate the full payload or RPC
merely to write two buttons; ordinary movement/correction/native timestamps must
not be republished with invented duration/sequence/position assumptions.

Investigate exact API, current-action readback, authoritative/local execution,
no-fresh-action interval and late overwrite ordering. Compare its extra native
effects, ownership and state against A. A durable brain write/lease, replaying
stale action timing or another movement protocol is not an accepted implementation.

## Senior decision target

Choose the smallest demonstrated coherent native join that feeds retained VR
primary high→low through original operator and held consumers. Keep full stock
weapon/multiplayer scope; a single saw proof is an incremental vertical, not
completion or a blanket final class restriction. Require exact production wiring,
x86 entry/ordinary wrapper checks and source trace; portable scalar tests cannot
prove native callback consumption. User excludes runtime testing, not correctness.

Reopen only demonstrated incompatible boundaries. Do not introduce a second
ACK/freezing/edge/combat/controller layer to make the design easier to mock.

## Final Astra/xhigh disposition

Choose A for source implementation. B has a concrete incompatibility: the public
accepted-action call also republishes movement, support, position and correction
state; even copying current position can erase an outstanding correction. There
is no demonstrated partial-primary setter. See PRIMARY_NATIVE_ACTION_AUDIT.md.

| Finding | Disposition |
| --- | --- |
| Midoperator revocation and nested neutral can corrupt delivered-high history | Remove both; immutable V persists through the outermost same-pawn invocation |
| Same-pawn nesting may enter through another native caller | Inherit active V before ordinary caller/root admission checks |
| Native callbacks can equip, flip, release charged shots or send RPC | Retain native effects; do not remap V before native history commit |
| Reentrant preparation can observe a known VR pawn before its record is ready | Reserve recognized-neutral metadata before update/freeze/getters |
| Native mapping is an index and lone-left may map to index1 | Read the actual typed getter; do not infer mask or hardcode right/left bits |
| Two weapons can share unsupported mapping/topology | Recognized-neutral until actual uncoupled combo is established |
| High-level F6 query bypasses mapping/blocking | Replace with the five current-bit reads and original ordinary consumers |
| Accepted-action replay changes unrelated correction/transport | Reject B; no synthetic action payload, raw brain store or sixth replication hook |

For one admitted outer invocation, each intercepted scalar becomes
`(original & ~0x03) | (V & 0x03)`. EDI at8E5BB, CL at8E5E0/8E610/8E75A,
and EAX at8E4DD retain their upper/unmanaged bits. Native history348,
blocking161, flip, callbacks, inventory and weapon FSM remain original.
Lifecycle invalidation revokes prepared metadata, not the active immutable V.
Later independent consumers revalidate without resampling or introducing a high.

This GO does not prove unconditional stock or multiplayer equivalence. Native
PreSendUpdate is an unadapted observer of raw primary state; no distinguishing
same-pawn callback path was found. Existing negotiated VR intent supplies the
multiplayer path; byte-for-byte native action replication is not claimed. A
demonstrated replacement/reset of the brain action during the outer invocation
would reopen the decision. Source wiring, ABI checks and independent source
review are required before the vertical is accepted. No runtime testing occurred.
