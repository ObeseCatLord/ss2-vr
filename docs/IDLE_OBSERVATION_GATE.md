# User-operated idle observation gate

The user performs primary gameplay tests. Do not launch more idle fixtures merely
to repeat file-open receipts, or ask for a final acceptance pass before the
remaining implementation is ready.

A complete resource-to-rendered-instance/grasp observation is **not ready**.
The private candidate remains `0.2.11-dev.ab9b8ce84e25`, IPC10/wire7, with source
fingerprint `ab9b8ce84e25309b47cce63c40711214b5e8ac9f96d050e22dd0d1f776e42e46`.
All 15 manifest payload hashes were checked locally. It has not been deployed;
the previous private lab has older products. No new game or debugger run occurred.

The existing loader observation proves successful file opens. It does not prove
which ordinary registered configuration backs the current rendered weapon.
Likewise, the palette callback comes after live animation contributors are
cleared; cache hits can skip evaluation. A stopped-process snapshot cannot recover
cleared information or supply historical loaded-byte provenance.

Astra/xhigh reviewed the alternative of a user-operated all-stop debugger
observation and returned NO-GO for sufficient alignment evidence at the currently
established boundaries. Backend execution remains unattested. The main adopted
the result and added no partial production observer or automatic offset.

The minimum collector prerequisite is a finite specification establishing exact
original ID1 gun-invocation admission; readable winning contributors and evaluated
pose with explicit cache handling; and bounded, interpretable current resource,
stretch, geometry and positively identified grasp evidence in the same admitted
observation. Unrelated/nested calls, ambiguous identity and unwind must reject.
The filter and reader are unimplemented. An indiscriminate core is insufficient.
This bounded review is terminal; it does not authorize another broad native census.

If those prerequisites are established, the smallest user collection is one hand,
one ordinary ID1 idle pose held for 10 seconds, with no shooting or vehicle test.
It could unlock one measured asset-specific grasp correction if a mismatch is
demonstrated. The matching private package/settings/scene/launch identity,
diagnostic schema, normal detach/quit and isolation evidence must accompany the
actual collector. Until then there is no ready collection command.

A visual idle assessment can identify visible misalignment, but cannot certify a
numerical offset or native resource provenance. Neither accepting that limited
assessment nor deferring certified grasp has been decided for the user.

First-use/copy physical-melee admission is a separate open feature. An idle model
capture cannot prove the original saw release or replace the required later quiet
witness. Physical driver-grab steering also remains open. See
[source closure](FULL_PROJECT_SOURCE_CLOSURE.md) and
[user test preparation](USER_VR_TEST.md) for implemented versus incomplete scope.
